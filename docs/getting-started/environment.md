# Environment Setup

Requirements:
- Python 3.10+
- Neo4j (Docker or local install)
- dbCAN database files (if running Stage 06)

Install:
- `python -m pip install -r requirements.txt`
- Optional LLMs: `python -m pip install -r requirements-llm.txt`

See also: ENVIRONMENT_SETUP.md in the repo root for detailed OS‑specific steps.
